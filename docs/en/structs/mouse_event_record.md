# WCI - Windows console interface

## [WCI](../wci.md) > Structure `MouseEventRecord`

Structure `MouseEventRecord` contains following fields:

- [`Coord`](./coord.md) `mousePosition`
- [`ButtonState`](../enums/button_state.md) `buttonState`
- [`ControlKeyState`](../enums/control_key_state.md) `controlKeyState`
- [`EventFlag`](../enums/event_flag.md) `eventFlags`

---

Structure `MouseEventRecord` is used for recording mouse input events for structure [`InputRecord`](./input_record.md).
