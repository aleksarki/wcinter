# WCI - Windows console interface

## [WCI](../wci.md) > Structure `SmallRect`

Structure `SmallRect` contains following fields:

- [`Wchar`](../types/wchar.md) `character`
- [`Attribute`](../enums/attribute.md) `attributes`

---

Structure `CharInfo` specifies a Unicode character and its attributes.
This structure is used by the console functions for reading from and writing to the console screen buffer.
