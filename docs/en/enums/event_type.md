# WCI - Windows console interface

## [WCI](../wci.md) > Enumeration `EventType`

Enumeration `EventType` is based off type [`Word`](../types/word.md) and provides following options:

- `KeyEvent` =              `0x01`: Event contains key event record.
- `MouseEvent` =            `0x02`: Event contains mouse event record.
- `WindowBufferSizeEvent` = `0x04`: Event contains window change event record.
- `MenuEvent` =             `0x08`: Event contains menu event record.
- `FocusEvent` =            `0x10`: Event contains focus change.
